# Bijdragen aan het No-Halu Model

Bijdragen zijn welkom. Een paar richtlijnen:

## Werkwijze
1. Fork de repository en maak een feature-branch (`feature/jouw-idee`).
2. Houd code in stijl met de bestaande PSR-12-conventies en `declare(strict_types=1)`.
3. Voeg tests toe voor nieuwe functionaliteit (`tests/`).
4. Open een pull request met een duidelijke beschrijving van het *waarom*.

## Tests draaien
```bash
composer install
composer test
```

## Reikwijdte
Dit project is een conceptueel/onderzoeksraamwerk. Pull requests die de
wetenschappelijke claims onderbouwen met reproduceerbare benchmarks zijn
bijzonder welkom. Vermijd het toevoegen van afhankelijkheden tenzij echt nodig.

## Gedragscode
Wees respectvol en constructief. Inhoudelijke kritiek op het model is
gewenst; persoonlijke aanvallen niet.
